# Membuat algoritma menghitung luas dan keliling lingkaran

```
1. Mulai
2. Masukkan nilai luas dan keliling lingkaran
3. Menghitung luas dengan hitung pi kali jari jari kuadrat
4. Menghitung keliling dengan 2 kali pi kali jari jari lingkaran
5. Mendapatkan hasil kedua nya
6. Selesai
```
